# Aidil Utility

A personal desktop utility application built with Python and Tkinter.

## Current architecture

- Responsive main application window
- Sidebar launcher for utility modules
- Independent floating utility windows
- Multiple utilities can stay open at the same time
- Optional Always on top behavior for floating windows
- Utility window position and size persistence
- Local window state storage in `data/window_state.json`

## Planned modules

- Dashboard
- Productivity
- PC Monitor
- File Tools
- Calculators
- Utilities
- Network
- Media
- Settings
- About

The Dashboard will eventually summarize local laptop activity such as active time, application usage, system resource usage, and other useful statistics.
